¿Para qué sirve este kit?

Busca ayudar a implementar de manera rápida el guardado y la carga de pixel arts sencillos para tus juegos, convirtiendo el dibujo en una cadena que se guarda dentro de 16 variables de guardado como máximo.

Limitaciones:

Las obras guardadas solo pueden tener 2 tamaños pre definidos y una paleta de 8 colores como máximo.

Además, como Fancade solo tiene 64 variables de guardado disponibles por juego, tendrás que medir cuántos slots de cada tipo puedes usar. En el caso de solo usar imágenes 8x14, tienes un máximo de 4 slots, en caso de usar solo de 8x8, tienes hasta 6 slots disponibles

Scripts:

En el kit están incluidas 2 variantes de los scripts. Se encuentran separadas por que se diseñaron para un tamaño específico de imagen.

Para distinguir uno de otro, hay 2 pixeles de colores que representan las dimensiones de la imagen que procesan y un dibujo en la parte posterior.

Los scripts que contiene el kit son:
  • Image Editor UI: Abre el editor de pixel art y cuando se termina de dibujar, devuelve una lista con la imagen. Puede recibir de entrada un color de fondo predeterminado.

    La lista "Image" que devuelve tiene tantos elementos como pixeles la imagen (contando los transparentes) + 8 variables de la paleta de colores.

  • Image To String: Permite convertir una lista de imagen en una mas óptima para guardar y cargar datos.

    Su única salida es la lista "String" que tiene un tamaño 16 para imágenes de 8x14 y tamaño 10 para imágenes de 8x8.

  • String To Image: Hace exactamente lo mismo que Image To String pero al revés, devolviendo una lista "Image"

  • Save String 1/2/3/..: Guarda cada elemento de una lista de string en una variable de guardado y tiene una variante por cada posible slot de la imagen.

  • Load String 1/2/3..: Carga cada variable de guardado de su slot correspondiente en una lista "String" que devuelve como salida.

  • Image To Object: A partir de una lista image, construye un pixel art que sigue a un unico pivote. Este script te devuelve tanto el object que representa al pivote, como una list con los pixeles de la imagen

    El tamaño de la lista de pixeles, es el mismo que el de la lista de entrada, pero restandole los 8 espacios que ocupa la paleta de colores.

  • Update Pos: Este script, a partir de un pivote válido otorgado por Image To OBject, actualiza la posición y rotación de la lista de pixeles para seguir a las del pivote.

Ejemplo completo:

A continuacion, se mostrará una forma sencilla de implementar el kit con su funcion mas básica: guardar el dibujo de un jugador y despues cargarlo en otro nivel.
(Que es precisamente el ejemplo mostrado en los niveles "Example" y "Saved Example")


  1. Guardar:

    En el nivel donde se creará el pixel art, construiremos este flujo sencillo, donde tras terminar el dibujo, la imagen resultante se convertirá a string, el string se guardará y el nivel acabará.

  2. Cargar:

    Ahora, en el nivel donde se cargará el dibujo anterior, se recuperará con un Load String del mismo slot donde guardamos el string (en este caso slot 1).
    Posteriormente, se convierte con String To Image, creamos los objetos con Image To Object y finalmente, para posicionarlo, movemos el pivote con un Set Position y lo actualizamos con Update Pos.

Nombres reservados

Este kit, utiliza algunas variables globales, y obviamente variables de guardado cuyos nombres y tipos se mencionarán brevemente aquí para evitar accidentes:

  • $ImgObjManage - Object

  • $ImgObjManCount - Num

  • $ImgObjManType - Num

Para las variables de guardado, se utilizan nombres con la estructura: "!SDNXSY" Donde "Y" representa el slot en el que se guarda y "X" el espacio dentro de ese slot. Si se usa la versión para imágenes 8x8, habra una "B" al final ("!SDNXSYB")
